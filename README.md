# ALEGRARTE

Landing page para **ALEGRARTE** — recreación y eventos en Bogotá.

## Stack

React 19 · TypeScript · Vite 6 · Tailwind CSS 4

## Comandos

```bash
npm install
npm run dev
npm run build
```

## Secciones

- Hero
- Servicios (tarjetas con imagen)
- Proceso (3 pasos)
- Paquetes (tarjetas de precio, sin tablas)
- Testimonios
- Galería (masonry)
- FAQ
- Contacto
